**Top gaps still open**

1. The built-in terminal UI cannot queue messages while a turn runs (CLI-27), has no resume selector (CLI-17) and no typed `/fork` selector (CLI-18).
2. Context-file discovery has no parent-directory walk and no `AGENTS.override.md` (CLI-44).
3. Missing flags and spellings: `--export`, `--session-id`, `--tui-mode`, `--approve`/`-na`, `--no-mcp`, `--verbose`, `--append-system-prompt` repeated (CLI-55 to 58, 63, 31, 32).
4. Settings: 21 of Pi's 73 keys are not acted on, including the resource arrays and `defaultProjectTrust` (CLI-39, 65), and settings writes are not locked (CLI-40).
5. Smaller command gaps: `/import`, `/mcp` management, `mcp list --json`, `uninstall` and the `update` options, RPC retry commands (CLI-59, 60, 37, 34, 7).

**Questionable upstream features we should NOT copy**

- `/share` to a GitHub gist or Radius, and `/bug` upload: they upload session contents to third parties and tie Koine to Pi's services. Local HTML export is enough (CLI-62).
- `pi update` self-update, version check and install telemetry (`enableInstallTelemetry`, `PI_TELEMETRY`): phone-home behaviour does not belong in a Go binary, and package managers do the job.
- `codemode` (QuickJS tool scripting) and `tool_search`: they add a sandbox and a large surface, and they are not needed for a usable agent.
- Fifty-plus terminal-rendering settings (`fullscreen*`, `terminal.*`, `markdown.mermaid`, `outputPad` and similar): they are coupled to Pi's TUI and add nothing in line mode.
- Silent legacy migrations (`oauth.json`, sessions at the agent root, `commands/` to `prompts/`): they exist only for Pi's own history, and Koine has none to carry.
