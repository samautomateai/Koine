**Top 5 gaps**

1. Session persistence and resume (CLI-15, 16, 17, 19): conversations vanish on exit, and REQ-SESS-001 is still "planned".
2. Non-interactive plumbing (CLI-01 to 04, 48): there is no positional prompt, no piped stdin, no auto print mode, and no clean stdout/stderr split. These are the minimum for scripting.
3. Compaction (CLI-24): history is unbounded, so long tasks will hit the provider's context limit.
4. Machine-readable modes (CLI-06, 07): JSON events are a small emitter over the existing events, and RPC needs steer, abort and state commands.
5. Flags for model, tools and resources (CLI-12 to 14, 29 to 31), plus credentials storage (CLI-36) and Pi's settings schema (CLI-38, 39).

**Questionable upstream features we should NOT copy**

- `/share` to a GitHub gist or Radius, and `/bug` upload: they upload session contents to third parties and tie Koine to Pi's services. Local HTML export is enough.
- `pi update` self-update, version check and install telemetry (`enableInstallTelemetry`, `PI_TELEMETRY`): phone-home behaviour does not belong in a Go binary, and package managers do the job.
- `codemode` (QuickJS tool scripting) and `tool_search`: they add a sandbox and a large surface, and they are not needed for a usable agent.
- Fifty-plus terminal-rendering settings (`fullscreen*`, `terminal.*`, `markdown.mermaid`, `outputPad` and similar): they are coupled to Pi's TUI and add nothing in line mode.
- Silent legacy migrations (`oauth.json`, sessions at the agent root, `commands/` to `prompts/`): they exist only for Pi's own history, and Koine has none to carry.
