# Gap assessment: Tools, agent loop, context, prompts, TUI

Upstream: Pi 1.5.2 (TypeScript). Audited on 2026-11-12 against Koine at `origin/main` 1059650 (after PRs #13 to #34) and against Pi's documentation at
https://pi.dev/docs/latest (usage, configuration, slash commands, skills, prompt templates, compaction, CLI, Windows). Pi's source files could not be
fetched in this audit, so rows that depend on exact wording or layout say so. Every HAVE row names code and a test that exists. Statuses are HAVE,
PARTIAL, MISSING and BY DESIGN; the priority of a PARTIAL or MISSING row is how much the remaining gap costs a Pi user (HAVE and N/A-by-design rows carry none), and a note says when it was lowered. See [the
summary](../gap-assessment.md).

**Biggest remaining gaps**

1. CTX-01 (P1): context files are read from the agent directory and the working directory only. Pi also reads every parent directory, so a run in a
   monorepo subdirectory misses the root `AGENTS.md`. The change is small (`LoadContextFiles`) and has no dependency.
2. AGT-02/03 (P1): steering and follow-up queues work in the core, over HTTP/RPC, in the Bubble Tea client and in the desktop app, but the built-in TUI
   (`core/tui`), which is the default interactive UI, blocks input while a turn runs. Alt+Enter and Alt+Up exist nowhere.
3. SKL-03 (P1): `disable-model-invocation` is not read, so a skill meant for explicit `/skill:name` use is offered to the model.
4. TPL-01, TPL-03, TPL-04 (P1 for quoting, P2 for the rest): prompt templates have no quoted arguments (`"a b"`), no `${1:-default}` or `${@:N}`, no `argument-hint`, and no
   first-line description fallback.
5. Smaller, all P2 or P3: the built-in TUI shows no live `bash` output (TOOL-14); compaction lacks split-turn summaries, stored `details`, `stopReason:
   length` recovery and `compaction.modelOverrides` (CMP-01, 03, 04, 05, 08); image paste (TUI-12); fullscreen copy-on-select, prompt jumps and search
   (TUI-01); `/import`, `/changelog`, `/debug` (SESS-03, CMD-04); the `powershell` tool (TOOL-16).

Closed since the first pass of this file: streaming (AGT-01), token and cost tracking (CMP-07), compaction and overflow recovery (CMP-02, mostly
CMP-01/05), sessions and the tree (SESS-01, TUI-11), parallel tools and hooks (AGT-04..06), thinking levels (AGT-08), the system-prompt hook (SYS-03),
the structured prompt and tool selection (TOOL-21, 22), the tool parity set (TOOL-05..13, 17..19, 23), export and `/copy` (TUI-16), selectors and
images in the TUI (TUI-10, 12), and most of the interactive UI (TUI-02..05, 07, 09, 13..15).

**Questionable upstream features we should NOT copy**

- `codemode` tool and `codemode.mode: only` (settings.md): hides tools behind script execution, which adds attack surface and indirection. Not needed
  for parity.
- `/share`, `/bug`, bug-report upload and telemetry (TUI-17): they send session contents or diagnostics to a third party. They are a privacy risk.
- `AGENTS.override.md` (CTX-02): a Pi-only convention that silently changes which instructions apply, and no other ecosystem uses it.
- `bash` with no default timeout: a hung command stalls the run forever. Koine's 120s default is safer, so keep it configurable instead.
- Easter eggs, branding and extras such as `armin.ts`, `easter-egg-3d` and `pi-logo.ts`: no coding-agent value.
