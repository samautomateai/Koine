**Top 5 gaps**

1. AGT-01: no streaming. Responses block until complete, which hurts every frontend and affects interrupt latency.
2. CMP-01/02 and CMP-07: no token accounting and no compaction, so long sessions overflow the context window. SESS-01 (persistence) is a prerequisite.
3. TOOL-12/17/18/07/08/09: the built-in tools are weaker than Pi's. bash output is cut by characters with no temp file, grep has no .gitignore support, `find` is named `glob`, and `edit` has no multi-edit, fuzzy match or line-ending preservation.
4. AGT-02/03/04/08: no steering or follow-up queue, no parallel tool execution, no thinking levels. The TUI blocks input while a run is active.
5. TUI-01/03/05/09: the interactive UI is line mode, or an uncompiled Bubble Tea app with no autocomplete, markdown, history or footer. CTX-01 (parent-directory AGENTS.md) and TPL-02..04 are small fixes with high compatibility value.

**Questionable upstream features we should NOT copy**

- `codemode` tool and `codemode.mode: only` (settings.md): hides tools behind script execution, which adds attack surface and indirection. Not needed for parity.
- `/share`, `/bug`, bug-report upload and telemetry: they send session contents or diagnostics to a third party. They are a privacy risk.
- `AGENTS.override.md`: a Pi-only convention that silently changes which instructions apply, and no other ecosystem uses it.
- `bash` with no default timeout: a hung command stalls the run forever. Koine's 120s default is safer, so keep it configurable instead.
- Easter eggs, branding and extras such as `armin.ts`, `easter-egg-3d` and `pi-logo.ts`: no coding-agent value.
