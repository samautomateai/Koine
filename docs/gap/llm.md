**Top 5 gaps**

1. LLM-02, streaming. REQ-LLM-003 is only planned, so there are no live tokens in any frontend and long turns feel dead.
2. LLM-11 and LLM-28, the model catalog plus usage and cost tracking. Nothing downstream (context %, compaction, image gating, thinking support) can work without model metadata.
3. LLM-22 and LLM-23, reasoning/thinking levels with thinking-block replay. Modern Claude and GPT models need them for quality and for tool-call correctness.
4. LLM-25 and LLM-31, prompt caching and context-overflow detection. Together with compaction (outside this area) these keep long agent sessions affordable and alive.
5. LLM-14, LLM-15 and LLM-42/45, credentials and MCP. Koine has no credential store or `!command` secret resolution, and no MCP stdio client or config. `!command` secrets give keychain support cheaply, and MCP is the main ecosystem-compatibility hole.

**Questionable upstream features we should NOT copy**

- Cache warming (LLM-26): background keep-alive requests that spend money on a 15% idle-continuation guess. It adds a scheduler and cost risk for small gains.
- Classifier and image-generation model types with TypeSafe/Jev, Cloudflare System One and OpenAI Decisions (LLM-39): vendor-specific, not coding-agent essentials, and they add a second model abstraction.
- Radius, Xiaomi/Qwen/ZAI token-plan regional provider entries, and Radius OAuth (LLM-10, LLM-20): affiliate or region-variant providers that add maintenance. Ship a generic `baseUrl` + env-key mechanism, and let users add them through custom providers.
- Virtual-model routers with session-branch state (LLM-38): a large coupling between sessions, extensions and model dispatch. A simple model-per-subagent setting covers most real use.
- Automatic, default-on codemode activation, and the `codemode` default exposure for MCP tools (LLM-46/48): MCP tools stay invisible to the model until it writes scripts. That is surprising and hard to permission-gate, since nested calls bypass the model's visible tool pipeline. Default MCP tools to `direct`, with deferred search as an opt-in.
