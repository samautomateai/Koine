# Changelog

All notable changes. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow semver once released.

## Unreleased

### Changed

- The model catalog now follows Pi's catalog (https://pi.dev/models) for the Claude models: all 15 current entries with Pi's context windows and prices; the unverified Haiku long-context multiplier is gone. `--skill` and `--prompt-template` now obey the trust gate like `-e`: in an untrusted folder they are skipped with a warning. (REQ-LLM-004, REQ-CLI-002)

### Added

- Fullscreen (alternate-screen) terminal UI and inline images (REQ-TUI-002, REQ-TUI-003, TUI-01, TUI-12). `tuiMode: "fullscreen"` (opt-in; Koine's default stays `regular`) shows the transcript in a scrollable viewport with `tui.altScreen.*` keys, the mouse wheel (`fullscreenWheelScrollLines`), a scrollbar (`fullscreenScrollbar`) and `fullscreenExitOutput`. Images from tool results and resumed sessions are drawn with the kitty or iTerm2 protocol (`terminal.images`, detected from the environment), honouring `terminal.showImages` and `terminal.imageWidthCells`, with a text placeholder elsewhere. Image paste, copy-on-select, prompt jumps and transcript search are not done.

- `docscheck` fails when two ADR files share a number.
- Cloud providers and provider robustness (REQ-LLM-012..015, ADR 0008). Amazon Bedrock (`amazon-bedrock`, Converse and ConverseStream) signs with SigV4 or a Bedrock API key (`AWS_BEARER_TOKEN_BEDROCK`), reads AWS keys from the environment or a shared-file profile, and decodes the event stream itself; Google Vertex AI (`google-vertex`) takes a `GOOGLE_CLOUD_API_KEY` or Application Default Credentials (service-account key file or gcloud login) with `GOOGLE_CLOUD_PROJECT` and `GOOGLE_CLOUD_LOCATION`. Changing model or provider mid-session now converts a copy of the history (thinking of another model becomes text, tool call ids are rewritten to the target\'s rules, orphan calls and results are repaired) and leaves the session file as it was. `KOINE_CACHE_RETENTION=long` asks for Anthropic\'s one-hour cache and OpenAI\'s 24-hour retention, OpenAI and Azure get `prompt_cache_key`, and the global `cacheWarming` setting (`off`, `streaming`, `idle`, default `idle`) refreshes a prompt cache before it lapses for models that declare `promptCache` when that saves at least $0.05. Not done: SSO, assumed roles and instance credentials for AWS, the metadata server and Claude for Google, Gemini thought signatures. Fake-server tested only; the live APIs were not exercised. Gap rows LLM-06, 07, 21, 24, 25, 26.
- Extension API parity and RPC mode (REQ-EXT-005..010, REQ-RPC-001; gap rows EXT-12..17, 19, 20, 22..26, 28, 29, 45 and CLI-07). `koine --mode rpc` serves Pi's RPC protocol: JSON commands on stdin (prompt with `streamingBehavior`, steer, follow_up, abort, session, model, thinking, queue, compaction, bash, state, entries and tree commands), responses, the JSON event stream and `extension_ui_request` dialogs on stdout. Extensions get real `ctx.mode`, `ctx.hasUI` and `ctx.signal`, dialogs (`select`, `confirm`, `input`, `editor`), `setStatus`, `setWidget`, `setTitle`, `setWorkingMessage`, `setEditorText`, `ctx.shutdown()`, `ctx.executeTool`, `pi.sendMessage` (custom messages with `triggerTurn` and `deliverAs`), `pi.getCommands`, a `pi.events` bus shared by all extensions and argument completion for commands (colliding command names are numbered `name:1`, `name:2`). Event handlers behave as in Pi: in-place `tool_call` input changes, chained `tool_result` and `input` handlers (images, details, `handled`, real `source`), `before_agent_start` with `systemPrompt` and `message`, a throwing `tool_call` handler blocks the call and other handler errors are reported as `extension_error`. New events: `session_shutdown`, `session_before_switch`, `session_before_fork`, `session_before_compact`, `session_before_tree` (answer `{cancel: true}`), `session_compact`, `session_tree` and `tool_execution_start|update|end`. Tool arguments are coerced and checked against the tool's schema before the tool runs. The terminal UI draws extension statuses, widgets, titles and the working message. Not done: message and entry renderers, `message_*` and provider events, custom compaction or summaries from gates (see `compat/DIVERGENCES.md`).
- MCP client (REQ-MCP-001..003): servers over stdio and streamable HTTP (JSON or SSE) from `mcp.json` in the agent directory and the project (also Claude's `.mcp.json` and opencode's `mcp` block), with `${ENV}` and `!command` secrets, `enabled`, `timeout` and `description`. Tools are registered as `mcp__server__tool` with `direct`, `deferred` (`tool_search`) or `hidden` exposure per server and per tool, results become text and images with a 20 KB middle cut, and `list_mcp_resources`, `list_mcp_resource_templates` and `read_mcp_resource` expose resources. OAuth for remote servers (discovery, dynamic registration, PKCE, token refresh, tokens in `mcp-auth.json` at mode 0600). `koine mcp add|remove|list|login|logout` and `/mcp`. Project servers wait for trust. Not covered: codemode, Client ID Metadata Documents, `--no-mcp`, annotations in `tool_call` events (`compat/DIVERGENCES.md`). Gap rows LLM-42..47, CLI-37.
- Provider auth and breadth (REQ-AUTH-001, REQ-AUTH-002, REQ-LLM-007..011). Credentials come from `--api-key`, then `auth.json` (mode 0600, written by `koine auth login` or `/login`), then `models.json`, then Pi's environment variables; a key can be `!command` or `$VAR`. `models.json` in the agent directory (and in a trusted project) defines providers and models in Pi's schema. New providers: OpenAI Responses (`api: "openai-responses"`), Azure OpenAI, Google Gemini, Mistral, Groq, Cerebras, xAI, OpenRouter, DeepSeek, Together, Fireworks, Hugging Face, NVIDIA, Moonshot, Vercel AI Gateway, Z.AI, and local Ollama, LM Studio, vLLM, SGLang and llama.cpp; provider errors show the message from the body with a hint for 401, 402 and 403. `koine auth login|logout|check|print-api-key|print-bearer-token`, and `/login` and `/logout` in line mode and in the terminal UI (a prompt that hides the key). Not done: OAuth, Bedrock, Vertex. Fake-server tested only; endpoints not compared with Pi's registry.
- Pi packages (REQ-PKG-001..003): `koine install|remove|update|list|config [-l]` manages packages from `npm:` (pinned versions stay put), `git:`/URL (tags and commits stay put) and local paths, for the user (`~/.koine/packages`) or the project (`.koine/packages`, trusted folders only). A package supplies extensions, skills, prompts and themes through the `pi` key of its `package.json` or the conventional directories; the `packages` setting takes source strings or objects with `!pattern`, `+path` and `-path` filters and `autoload`. Package resources feed the extension, skill and prompt loaders. npm runs with `--ignore-scripts` unless `--allow-scripts` or `allowInstallScripts` says otherwise; installs are recorded in `packages.lock.json` with a sha256 of the files, a changed package is refused and a package that no longer matches its lock is not loaded; host packages in `dependencies` give a warning; `koine update` prints the changelog of updated packages. Nothing is installed at startup. Tools, commands, skills and prompts carry a `SourceInfo` (`/packages`, `/sources`); extensions can add skill, prompt and theme paths by answering `resources_discover` (also for Pi's JS handlers); a directory `package.json` with `pi.extensions` is one extension. Tested with fake `npm`, local git repositories and local packages only; filter precedence and `autoload` follow Pi's guide as read, unverified.
- Interactive terminal UI in regular mode (REQ-TUI-001, TUI-02..11, 13..15): multiline editor with kill ring, undo, paste markers and history; `/`, `@` and Tab completion; markdown, tables and highlighted code; tool calls with edit diffs and Ctrl+O expand; footer with context, tokens and cost; selectors for model (Ctrl+L), thinking, settings, themes and scoped models; `/tree` navigator; external editor, suspend, thinking toggle, Esc interrupt, trust prompt; `keybindings.json`; JSON themes with `--theme`, `--use-theme`, `--no-themes`. Settings `theme`, `quietStartup`, `editorPaddingX`, `outputPad`, `autocompleteMaxVisible`, `showHardwareCursor`, `externalEditor`, `doubleEscapeAction`, `terminal.*` and `markdown.codeBlockIndent` are acted on. Fullscreen mode and images are not. `KOINE_LINE_MODE=1` keeps the old line loop.
- Image input (REQ-LLM-006, REQ-CLI-005): `@file` arguments and piped data that are images by content go to the model as images, and `read` returns image files as attachments. PNG, JPEG and GIF are resized to at most 2000 by 2000 pixels (and 4.5 MB) with `images.autoResize`; WebP and BMP go unchanged. Anthropic image blocks and OpenAI `image_url` parts; models whose catalog `input` lacks `image`, and `images.blockImages`, replace images with a text note. Images are stored in session files in Pi's shape, replayed, and written by `--mode json`. Fake-server tested only.
- Built-in tool parity with Pi (REQ-TOOL-002..005). `read` returns plain text cut at 2000 lines or 50KB with a continue hint. `edit` takes `edits[]` matched against the original, with fuzzy matching, BOM and CRLF preservation, all-or-nothing, a unified diff and the first changed line, and is queued per file with `write`. `bash` keeps the output tail with the full output in a temp file, kills the whole process tree on timeout or abort, reports partial output, and honours `shellPath` and `shellCommandPrefix`. `grep` (ripgrep or a Go search) and `find` (renamed from `glob`) respect `.gitignore`; `ls` has Pi's limit and order. Paths accept `~`, `@` and unicode spaces. `read`, `bash`, `edit` and `write` are the default tools (`grep`, `find`, `ls` are opt-in). Tools carry `promptSnippet`/`promptGuidelines` into the new `<tools>`/`<rules>`/`<project_context>`/`<environment>` system prompt sections, including extension tools. `!cmd` and `!!cmd` run a shell command in interactive frontends.
- Command-line parity (REQ-CLI-002..004): `-xt/--exclude-tools`, `-nbt/--no-builtin-tools`, `-t` patterns and `+name,-name`; `-e`, `--skill`, `--prompt-template`, `-ne`, `-ns`, `-np`, `-nc` (`--theme` options are accepted and ignored); fuzzy `--model`, `--provider`, `--models` and `enabledModels` (first match starts the session), `--api-key`, `--list-models`; extension options from `pi.registerFlag` (shown by `--help`); `AI_AGENT=koine`, `KOINE_CODING_AGENT` and `KOINE_SESSION_*` for the bash tool. `--mode json` now writes Pi's JSON event stream (session header, agent, turn, message and tool_execution events) instead of Koine's own events, and keeps notices on stderr. The stream now has every event of Pi's schema: `queue_update`, `entry_appended`, `session_info_changed`, `thinking_level_changed`, `compaction_start/end` (manual, threshold, overflow), `auto_retry_start/end`, `summarization_retry_*` and `tool_execution_update`; these are ordinary agent events, so the HTTP server sends them too. Assistant messages carry `api`, `thinkingLevel` and an always-present `usage.cost`. Extensions: `pi.appendEntry` stores a custom session entry, `pi.sendUserMessage` takes `deliverAs` (steering and follow-up queues) and a tool's `onUpdate` streams partial output. `/name --clear`; thinking changes are recorded as `thinking_level_change` entries; `KOINE_SESSION_REASONING_LEVEL` reaches the bash tool. `-e` extensions load only in a trusted folder (skipped with a warning otherwise); startup warnings are printed on stderr in print, JSON and server modes.
- Streaming and Pi's agent loop (REQ-LLM-003, REQ-AGT-001). Anthropic and OpenAI-compatible providers stream (server-sent events, optional `llm.Streamer`; non-streaming providers and plain-JSON answers still work) and the agent emits `text_delta`, `thinking_delta` and `tool_delta` before the unchanged final `text`/`thinking` events. `httpIdleTimeoutMs` / `retry.provider.timeoutMs` now bound the silence in a stream (default 300000 as in Pi). `Agent.Steer` and `Agent.FollowUp` queue messages typed during a run (`steeringMode`, `followUpMode`: `one-at-a-time` or `all`; events `queue_update` and `user_message`; `POST /api/steer` and `/api/follow-up`). Tool calls run in parallel after a sequential check, results in source order; hooks can override `isError` and `terminate`; cancelling keeps an `aborted` assistant message and answers every tool call; `context` event, `Agent.TransformContext` and `Agent.PrepareNextTurn`. `--mode json` writes streamed deltas as `message_update` records. Tested against fake servers only.
- Thinking levels and blocks, Anthropic prompt caching and retry settings (REQ-LLM-005). `--thinking LEVEL`, a `:level` suffix on `--model` and `/model`, `/thinking`, and the settings `defaultThinkingLevel`, `modelThinkingLevels`, `thinkingBudgets` and `hideThinkingBlock` set how hard Claude (adaptive effort or `budget_tokens`) and OpenAI-compatible reasoning models (`reasoning_effort`) think; the catalog gains a `reasoning` field. Thinking blocks are shown (as `thinking` events), kept, replayed to Anthropic with their signatures, and saved and restored in Pi's session shape. Anthropic requests cache the system prompt, the last tool and the last user message. `retry.enabled`, `retry.maxRetries`, `retry.baseDelayMs`, `retry.maxAgentDelayMs`, `retry.provider.timeoutMs`, `retry.provider.maxRetryDelayMs` and `httpIdleTimeoutMs` configure the retry loop, which now backs off exponentially from 2 s, honours `Retry-After`, skips quota errors and reports each retry; context-overflow detection knows each provider's wording. `cacheWarming` and cross-model thinking replay are not done.
- Session tree (REQ-SESS-002): `/tree [filter|id]` lists the entry tree and moves the conversation to an earlier entry, optionally summarising the branch it leaves (`--summary`; `branchSummary.reserveTokens`, `branchSummary.skipPrompt` and `treeFilterMode` now take effect); `/label` bookmarks entries; `/clone` and `/fork <id>` copy a branch to a new session; `/export [file]` writes JSONL or a self-contained HTML page; `-r` and `/resume` offer a numbered picker. v1 and v2 session files are migrated to v3 on load (original kept as `<file>.v<N>.bak`). Appends never alter existing lines of a Pi file, add a missing final newline, and copies keep entry lines (custom entries, unknown fields) as read. `/session` shows entry, branch and label counts.
- `$KOINE_AGENT_DIR` moves Koine's user directory (default `~/.koine`), like Pi's `PI_CODING_AGENT_DIR`. `SYSTEM.md` replaces and `APPEND_SYSTEM.md` extends the system prompt, from a trusted project (`.koine/` or `.pi/`) or else the user directory; `--system-prompt` and `--append-system-prompt` still win. (REQ-CFG-002)
- Model catalog and token accounting: built-in Claude context windows, output limits and prices (override or extend in `~/.koine/model-catalog.json`); usage from Anthropic and OpenAI-compatible responses is saved on each assistant message in Pi's `usage` shape, a `usage` event reports each response, and `/session` shows tokens, cost (or "unknown") and context use. Compaction now works from the provider's reported context size and takes the window from the catalog unless `compaction.contextWindow` is set. (REQ-LLM-004)
- Settings use Pi's key names in `~/.koine/settings.json` and `.koine/settings.json` (`config.json` still loads). `defaultProvider`, `defaultModel`, `defaultTools`, `sessionDir`, `extensions` and `compaction.*` take effect; every other Pi key is listed in `compat/settings.json` with its status and reported at startup if set. `task upstream:check` now also diffs Pi's settings. `$KOINE_SESSION_DIR` is now the session directory itself, like Pi's. (REQ-CFG-001)
- `docs/CHECKLIST.md`: documentation and parity-tracker updates are part of every change; CI now requires a `CHANGELOG.md` line plus a docs/tracker update, and a real reason for `Docs-Impact: none`.
- Compaction: automatic summarising before the context window fills, `/compact [focus]`, and one compact-and-retry on a provider overflow; saved in the session file (REQ-CMP-001). Settings under `compaction` in config.
- Sessions: conversations are saved in Pi v3 JSONL; `-c`, `--session`, `--fork`, `-n`, `--no-session`, `--session-dir`, `-r`, and `/new /session /name /resume /fork` (REQ-SESS-001). `/clear` is now an alias of `/new`.
- Scriptable command line: positional message, `@file`, piped stdin, `-p`, `--mode json`, `--model`, `--system-prompt`, `--append-system-prompt`, `-t`, `-nt`, `-h`, `-v`; answer on stdout, activity on stderr (REQ-CLI-001).
- `task deps:check` / `task deps:update` and a weekly `dependency-updates` workflow keep the Go toolchain, tool pins, action refs, Go modules and npm packages current (`scripts/deps.mjs`).
- Core agent with TUI, HTTP/SSE server, language-agnostic extension protocol, JS sidecar for Pi and opencode plugins, Claude-compatible hooks.
- Project trust gate, skill hidden-text audit, multi-provider routing.
- Pi compatibility manifest pinned to Pi 1.5.2, `koine -compat`, drift checker.
- CI quality gates: format, lint, size, coverage, dependency audit, vulnerability and security scanning for Go and JS.
- Requirements, design and ADR documents with automated consistency checks; agent configuration for Claude Code, opencode, Pi and Koine.
- Biome replaces Prettier and ESLint for JS; CI pins Go 1.27.4 and current action versions (ADR 0006).
- Desktop module: Wails v2.13.0 (fixes CVE-2026-34157, found by the Trivy gate).
- Parity gap assessment against Pi 1.5.2 (222 behaviours) with prioritised phases and eight planned requirements.
- UI modules pin fixed floors for vulnerable transitive dependencies (x/net, x/text).
- Dependabot opens one grouped PR per ecosystem per month (majors stay separate).
- Go 1.27.4 is the toolchain in all modules; CI reads it from go.mod.
